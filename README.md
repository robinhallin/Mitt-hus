# Dotterns spel

Det här repot används nu för ett nytt spel från grunden för en femåring på surfplatta/iPad.

## Utgångspunkt

- Intressen: bygga, pyssla och inreda.
- Målplattform: surfplatta/iPad.
- Utvecklingen och versionshistoriken hålls i detta GitHub-repo.

## Status

Det tidigare husprojektet har tagits bort från huvudgrenens aktuella filer. Det finns kvar på grenen `archive/house-before-kids-game-2026-10-19` och i Git-historiken.

Det nya spelet är ännu inte implementerat. Nästa steg är att precisera spelidén tillsammans med beställaren: vad spelaren gör, grafisk stil och första spelbara innehållet. Spelmotor och projektstruktur väljs därefter.

Se [spelbriefen](docs/spelbrief.md) för kända krav och öppna designval.
